# 研招网报名照自测

上传照片，在浏览器本地逐项检测是否符合《网上确认图像采集标准》。

**照片不会上传到任何服务器**，全部解析和推理都在你的浏览器里完成。

## 检测项

### 文件与规格

| 项目 | 要求 |
|---|---|
| 图片格式 | 仅支持 jpg / jpeg |
| 文件大小 | 建议不超过 10 MB |
| 宽高比例 | 严格 3:4（0.750） |
| 分辨率 | 建议不低于 480×640 |

### 人像姿态

| 项目 | 要求 |
|---|---|
| 人脸检出 | 须检出且仅检出 1 张正脸 |
| 眼睛高度 | 瞳孔距照片上边沿为图像高度的 30%–50% |
| 人像水平居中 | 人像水平居中、左右对称 |
| 倾斜角 / 水平转动角 / 俯仰角 | 应在 ±10° 之内 |
| 头部与肩部占比 | 人像占整张照片的比例不小于 2/3 |
| 双眼睁开 | 双眼自然睁开并平视 |
| 嘴唇自然闭合 | 嘴唇自然闭合、表情平和 |

### 背景与画质

| 项目 | 要求 |
|---|---|
| 背景底色 | 白色或蓝色背景（以报考点要求为准） |
| 整体亮度 | 照明光线均匀，不过暗也不过曝 |
| 过曝情况 | 无高光、光斑 |
| 清晰度 | 人像对焦准确、层次清晰、不模糊 |

## 参考线是怎么来的

照片预览上的青色参考线，复刻自研招网照片预览页自带的遮罩图（`bg-line.png`，480×640）。
按像素级实测，其几何为：

- **两条竖线**：画面宽度 25.0% 与 74.9%，贯穿全高 → 人像水平居中 / 左右对称参考
- **一条横线**：画面高度 39.0%，且**只画在两条竖线外侧，不穿过面部** → 眼睛高度基准线

横线的 39% 正是官方「眼睛所在位置距离照片上边沿为图像高度的 30%–50% 之间」这条区间的中值。
横线不横穿人脸，是为了避免遮挡五官，只作瞄准线用。

## 实现说明

- 人脸关键点与头部姿态：MediaPipe Tasks Vision `FaceLandmarker`（478 点 + 虹膜 + 三维变换矩阵），运行时与模型均已本地化，不依赖任何 CDN。
- 背景底色与人像占比：从画面四边对背景色做泛洪填充，得到背景掩膜后再统计，因此白色衬衫、浅色皮肤不会被误算成背景。
- 过曝统计只在人像区域内进行，白色背景不计入。
- 清晰度使用拉普拉斯方差，并先把亮度对比度归一化，避免「照片偏暗」被误判成「照片模糊」。
- 三个姿态角由三维模型解算，存在约 ±5° 的模型误差；判定上 ≤10° 通过、10°–13° 提示复核、>13° 不合格。

## 无法自动判定的项

以下要求属于主观项，工具无法判断，需要自行核对：

- 近三个月内拍摄、图像真实表达本人近期相貌
- 不得化妆、不得佩戴眼镜 / 隐形眼镜 / 美瞳 / 饰品
- 脸部无遮挡，头发不得遮挡眼睛、眉毛、耳朵或造成阴影
- 不得使用 PS 等软件处理，不得对人像特征（伤疤、痣、发型等）做技术修改
- 不得用照片翻拍

最终审核结果以报考点为准。

## 本地运行

由于使用 WebAssembly，需要通过 HTTP 访问，不能直接双击打开 `index.html`：

```bash
python3 -m http.server 8899
# 浏览器打开 http://127.0.0.1:8899
```

## 检测项来源

- 「眼睛所在位置距离照片上边沿为图像高度的 30%-50% 之间」「人像水平居中」「±10 度」
  「头部和肩部……需占整张照片的比例为不小于 2/3」等条款，出自各报考点发布的
  《网上确认图像采集标准》（官方统一表述）。
